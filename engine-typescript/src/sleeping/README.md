# sleeping

Helpers that put bodies to sleep and wake them, over component data and the sleep resources. The `sleep` system decides when bodies fall asleep; everything that wakes a body goes through these helpers. Layer: physics.

| File            | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `wakeBodies.ts` | `installSleepResources`, `disturbs` (a body with no sleep timer or with a timer at 0 wakes the sleepers it touches), `fallAsleep` (zero motion, tag `Asleep`, record the group), `wakeBody` (wakes the body's whole recorded group after the current system), `wakeBodyNow` (wakes the group at once, for a system that needs the woken bodies movable in the same step), `wakeAllBodies` and `wakeBodiesOverlapping` (sleepers whose bounds touch a rectangle, with a 1 px margin) |
| `worldEdits.ts` | Changes without motion that wake the sleepers they affect: `destroyBody` (its group, overlapping sleepers and joint partners), `moveStaticBody` (sleepers at the old and new bounds) and `setCollisionGroup`                                                                                                                                                                                                                                                                        |
| `UnionFind.ts`  | Disjoint sets over integer indices with path compression and union by size, used to build islands                                                                                                                                                                                                                                                                                                                                                                                   |
