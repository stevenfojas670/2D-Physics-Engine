# systems

Physics systems. Each file exports a factory `createXSystem(world)` that builds its views once and returns a `System` to add to a `Schedule`. Layer: physics.

| File                           | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `BroadPhaseSystem.ts`          | Refills the broad-phase grid from collider bounds and builds the step's candidate pairs, each unordered pair once, filtered by the collision matrix                                                                                                                                                                                                                                                                            |
| `ColliderTransformSystem.ts`   | Recomputes each awake collider's world vertices, bounds and (when rotated) normals from its transform; runs after integration so rendering and next step's broad phase see final positions                                                                                                                                                                                                                                     |
| `ContactDetectionSystem.ts`    | First wakes every sleeper whose bounds touch a disturbing body, so the hit moves it this step; then runs the narrow phase once per candidate pair and stores the manifolds with body slots, inverse masses (zero for a body without `Mass` or `Velocity`, or with `Asleep`), combined materials (max restitution, geometric-mean friction) and impulses carried from last step; owns the `touching` flags and records contacts |
| `GravitySystem.ts`             | Adds gravity times mass to every awake movable body's force accumulator                                                                                                                                                                                                                                                                                                                                                        |
| `IntentForceSystem.ts`         | Turns `MovementIntent` into force: 500 per axis, plus ten times that upward for a jump; a non-zero intent wakes the body                                                                                                                                                                                                                                                                                                       |
| `JointForceSystem.ts`          | Applies spring and force joints at their anchors, sets each spring's `stretchState`, skips joints whose bodies are gone or can't move (static or asleep), never pushes a sleeping end, and wakes a sleeper joined to a disturbing body                                                                                                                                                                                         |
| `ParticleIntegrationSystem.ts` | Integrates particles: base acceleration plus force, damping per second, accumulator cleared                                                                                                                                                                                                                                                                                                                                    |
| `PositionIntegrationSystem.ts` | Moves awake rigid bodies by velocity plus split-impulse pseudo-velocity times the step, then clears the pseudo-velocities                                                                                                                                                                                                                                                                                                      |
| `PseudoVelocitySolveSystem.ts` | Split-impulse passes over the stored manifolds: pushes overlapping bodies apart through pseudo-velocities, never real velocity                                                                                                                                                                                                                                                                                                 |
| `SleepSystem.ts`               | Last in the step: counts how long each awake body that may sleep has stayed under the `SleepSettings` thresholds while touching something (any body counts in zero gravity), and puts a whole island to sleep once every member has passed the timeout                                                                                                                                                                         |
| `VelocityIntegrationSystem.ts` | Turns forces into awake rigid-body velocity, then per-step damping; clears the accumulator and moves nothing                                                                                                                                                                                                                                                                                                                   |
| `VelocitySolveSystem.ts`       | Warm-starts the stored manifolds, then runs the velocity passes (normal and Coulomb friction impulses) and records friction arrows                                                                                                                                                                                                                                                                                             |
| `WindSystem.ts`                | Adds wind times exposure to the force accumulator of every awake body with `WindExposure`; bodies without a force accumulator are skipped                                                                                                                                                                                                                                                                                      |
| `WorldChangeWakeSystem.ts`     | First in the step: remembers gravity, wind, the collision matrix and its version, and `SleepSettings.enabled`, and wakes every sleeper when one changes                                                                                                                                                                                                                                                                        |
| `IslandSystem.ts`              | Right after contact detection: builds this step's islands with union-find over awake dynamic bodies, linked by manifolds and joints; statics link nothing                                                                                                                                                                                                                                                                      |
