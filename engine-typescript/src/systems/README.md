# systems

Physics systems. Each file exports a factory `createXSystem(world)` that builds its views once and returns a `System` to add to a `Schedule`. Layer: physics.

| File                           | Purpose                                                                                                                                                                                                                                                   |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BroadPhaseSystem.ts`          | Refills the broad-phase grid from collider bounds and builds the step's candidate pairs, each unordered pair once, filtered by the collision matrix                                                                                                       |
| `ColliderTransformSystem.ts`   | Recomputes each collider's world vertices, bounds and (when rotated) normals from its transform; runs last in the step so rendering and next step's broad phase see final positions                                                                       |
| `ContactDetectionSystem.ts`    | Runs the narrow phase once per candidate pair and stores the manifolds with body slots, inverse masses, combined materials (max restitution, geometric-mean friction) and impulses carried from last step; owns the `touching` flags and records contacts |
| `GravitySystem.ts`             | Adds gravity times mass to every movable body's force accumulator                                                                                                                                                                                         |
| `IntentForceSystem.ts`         | Turns `MovementIntent` into force: 500 per axis, plus ten times that upward for a jump                                                                                                                                                                    |
| `JointForceSystem.ts`          | Applies spring and force joints at their anchors, sets each spring's `stretchState`, and skips joints whose bodies are gone                                                                                                                               |
| `ParticleIntegrationSystem.ts` | Integrates particles: base acceleration plus force, damping per second, accumulator cleared                                                                                                                                                               |
| `PositionIntegrationSystem.ts` | Moves rigid bodies by velocity plus split-impulse pseudo-velocity times the step, then clears the pseudo-velocities                                                                                                                                       |
| `PseudoVelocitySolveSystem.ts` | Split-impulse passes over the stored manifolds: pushes overlapping bodies apart through pseudo-velocities, never real velocity                                                                                                                            |
| `VelocityIntegrationSystem.ts` | Turns forces into rigid-body velocity, then per-step damping and sleep thresholds; clears the accumulator and moves nothing                                                                                                                               |
| `VelocitySolveSystem.ts`       | Warm-starts the stored manifolds, then runs the velocity passes (normal and Coulomb friction impulses) and records friction arrows                                                                                                                        |
| `WindSystem.ts`                | Adds wind times exposure to the force accumulator of every body with `WindExposure`; bodies without a force accumulator are skipped                                                                                                                       |
