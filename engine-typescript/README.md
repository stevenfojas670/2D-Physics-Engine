
# 2D Physics Engine

A 2D physics engine built with TypeScript and Vite.

## Features

- 2D rigid body dynamics
- Collision detection and response
- Constraint solving
- Fast development with Vite

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Usage

```typescript
// Example usage
import { Engine } from './engine';

const engine = new Engine();
engine.start();
```
