# superpowers

Design specs and implementation plans for this repo.

| Folder | Contents | File naming |
|---|---|---|
| `specs/` | Design documents: what to build and why | `YYYY-MM-DD-<topic>-design.md` |
| `plans/` | Implementation plans: ordered, verifiable tasks | `YYYY-MM-DD-<topic>.md` |

Every plan links the spec it implements. Write the spec first, get it approved, then write the plan.
